## Requirements
 
- Python 3.1 or newer
- Jupyter (Notebook or JupyterLab)
- Python packages:
  - `numpy`
  - `scikit-learn`
  - `matplotlib`
  - `jax`
## Setup
 
Clone the repository:
 
```bash
git clone https://github.com/GiacomoSaporetti/FYS-STK4155-Project1.git
cd FYS-STK4155-Project1
```
 
Create a virtual environment (recommended) and install the dependencies:
 
```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install numpy scikit-learn matplotlib jax jupyter
```
 
## Running the code
 
Start Jupyter and open the notebook:
 
```bash
jupyter notebook Project1.ipynb
```
 
Then run all cells in order (**Kernel → Restart & Run All**). The notebook is organised by the parts of the project, so it should be run top to bottom, since later parts reuse the data and functions defined earlier.
 
Random seeds are fixed in the notebook, so re-running it should reproduce the same data, CV folds and numbers. Figures are saved to `Results/`.
 
## Building the report (optional)
 
To compile the report from the LaTeX source:
 
```bash
pdflatex Project1.tex
```
 
Run it twice if the references or table of contents are not updated. Make sure the figures in `Results/` have been generated first.
 
## Notes
 
- Lasso can emit convergence warnings at high polynomial degrees. These are suppressed in the notebook and do not stop execution.
- Running the full cross-validation grid over degrees and λ values can take a few minutes.
